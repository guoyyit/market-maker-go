# 风险语义

风控由 `internal/risk` 的单标的监视器维护，状态只有两种：

- `NORMAL`：正常根据意图维护两侧报价；
- `PROTECTED`：保护状态，已全量撤单，**不允许挂任何新单**。

## 进入保护的条件

### 1. 行情心跳超时

定时器事件携带检查时刻 `now`。当距最近一帧**有效**行情超过
`HeartbeatTimeout`：

```
NORMAL -> PROTECTED, reason = heartbeat_timeout
```

引擎收到该流转后**第一动作是全量撤单**，再持久化。保护状态下重复心跳
检查是静默的，不会重复产生审计记录。

### 2. 单笔价格异常跳变

相邻两帧**有效**行情的中间价变化绝对值超过 `MaxPriceJump`：

```
NORMAL -> PROTECTED, reason = price_jump
```

同样立即全量撤单。

### 3. 非法价差

行情帧 `Ask - Bid <= 0`（交叉/零价差）或 `Ask - Bid > MaxSpread`
（行情自身过宽）时：

```
NORMAL -> PROTECTED, reason = invalid_spread
```

## 异常帧不成为基准

触发跳变或非法价差的那一帧**不会**更新"最后有效行情"的中间价与时间。
这避免异常帧把后续正常行情再次锚定为跳变。心跳计时也始终从最后一个
有效帧起算。

## 退出保护（恢复条件）

进入保护后，只有收到一帧**同时满足**以下条件的行情才回到 `NORMAL`：

- 价差合法（`0 < Ask-Bid <= MaxSpread`）；
- 与最后有效帧的中间价跳变在 `MaxPriceJump` 以内（若此前无有效帧，
  则只要求价差合法）。

```
PROTECTED -> NORMAL, reason = recovered
```

恢复的同一事件中，引擎用最新行情与持仓重新生成意图并挂回两侧报价。
心跳超时的恢复不需要额外的定时器，正常行情帧本身即恢复信号。

## 全程可审计

每次状态流转（进入或退出保护）生成一条 `risk.Transition`：

- 内存中保留全量流转历史（按发生顺序）；
- 同时以**只增不改**的 JSONL 追加到存储目录的 `risk.log`，
  每行一条，含 from/to、原因、行情序号、时间与人类可读细节；
- 重启后审计历史从 `risk.log` 重新加载，跨进程连续。

保护状态本身也写入 `state.json`，重启时若处于保护状态，
恢复流程**先全量撤单且不重建报价**，直到满足恢复条件。
